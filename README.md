# SinsWorld Launcher

Обновлённый Python-лаунчер на основе присланного проекта. Minecraft 1.20.1, Forge 1.20.1-47.3.22 сохранены. Интерфейс — pywebview / Edge WebView2. Основное окно следует актуальным пользовательским концептам: тёмный замок, Мелиодас справа, изумрудный дракон, верхняя навигация, большая кнопка «Играть». Настройки состоят из карточек, вход и регистрация — отдельные формы без почты.

## Что изменено

- Стартовое вертикальное окно без названия: плавное увеличение, бегущие Мелиодас и Хоук, простой зелёный прогресс-бар.
- Плашка плавно меняет текст по реальному состоянию: проверка / обновлений нет / обновление / установка.
- GitHub Releases вместо Яндекс Диска и Google Drive. Лаунчер и моды используют разные каналы и отдельные экраны прогресса.
- SHA-256, размер скачивания, staging модов, откат при ошибке замены. Перед каждым запуском список JAR строго сверяется с манифестом; все лишние моды удаляются.
- Windows-помощник замены EXE после закрытия процесса; сохранение предыдущего EXE.
- Формы аккаунта без почты; явное разделение локального ника и настоящей серверной авторизации.
- Подготовлен видеофон трейлера: приглушённый, без звука, с паузой и статичным запасным фоном. Сам трейлер не предоставлен.
- Приложены инструменты генерации манифестов, автоматические тесты и Windows GitHub Actions workflow.

## Запуск на Windows

Для исходников нужны Python 3.11 и Microsoft Edge WebView2 Runtime. Java 17, Minecraft, Forge и библиотеки игры подготавливаются автоматически при запуске.

1. Распакуйте архив в отдельную папку с правами записи.
2. Откройте `start_launcher.bat`. Он создаст новое окружение и установит зависимости.
3. Каналы GitHub уже настроены на `Zairez1/SinsWorldLauncher`. При необходимости их можно изменить в настройках.
4. Убедитесь, что опубликованы теги Release `launcher-current` и `mods-current` с правильными assets. Подробно: `docs/GITHUB_UPDATES.md`.
5. Выберите ник и нажмите «Играть». Пользовательские настройки содержат память, разрешение, полноэкранный режим, папку игры и музыку.

Публичный репозиторий проекта: https://github.com/Zairez1/SinsWorldLauncher . Каналы обновления — `launcher-current` и `mods-current`.

## Сборка EXE

Запустите `build_windows.bat` на Windows. Результат — `dist/SinsWorldLauncher.exe` и `dist/launcher-manifest.json`. Альтернатива: загрузите содержимое проекта в корень GitHub-репозитория и запустите Actions workflow; дальнейшие изменения main публикуются автоматически.

В архиве нет старого EXE от предыдущей версии: он бы запускал прежний код. EXE версии 1.1.1 успешно собран на Windows runner GitHub Actions и опубликован в Release launcher-current. Скачивание и SHA-256 проверены. Интерактивный запуск EXE на пользовательском Windows-компьютере ещё не проверялся.

## Аккаунты

Для регистрации и входа введите в настройках `auth_api_url` своего сервиса. Адаптер и контракт описаны в `docs/AUTH.md`. Готового сервера авторизации в исходном ZIP не было, поэтому автоматический вход в AuthMe не заявляется работающим без серверной интеграции. Временный локальный профиль ведёт себя как прежний ввод ника и явно подписан в интерфейсе.

Пароли не сохраняются. «Запомнить меня» использует системное защищённое хранилище для refresh token. Для собственной Yggdrasil-авторизации необходимы проверенный authlib-injector и серверная проверка сессий.

## Трейлер и демонстрация

`docs/UI_AND_TRAILER.md` описывает прямую HTTPS-ссылку на MP4/WebM. Страницу YouTube нельзя использовать вместо видеофайла. В `demo/Launcher_Updater_Demo.html` — анимированный пример; ресурсы находятся рядом в ui/. Для браузерного просмотра запустите `python -m http.server 8000` из корня проекта и откройте http://localhost:8000/demo/Launcher_Updater_Demo.html . Открытие `ui/index.html` в браузере показывает основной интерфейс, но реальные операции требуют запуска Python.

## Данные и обновления

Настройки и игра остаются в `%APPDATA%/SinsWorldLauncher/`. Старые параметры Яндекс Диска могут сохраняться в пользовательском config, но новый updater их не использует. Настройки из этой папки имеют приоритет над корневым config.

Проверку модов нельзя отключить: недостающие и изменённые моды восстанавливаются, все JAR вне списка удаляются из папки mods, включая вложенные папки. Сохранения и настройки остаются. Не запускайте два экземпляра лаунчера для одной папки игры.

### Solo Leveling

В списке серверов доступен Solo Leveling с пометкой «Скоро». Выбор сохраняется и меняет фон, цвета интерфейса и вертикальный загрузочный экран. Игровой запуск и синхронизация модов для этого сервера заблокированы до открытия. Для локальной сборки скачайте `solo-scene.png` и `naruto-scene.png` из релиза `auth-bridge-current` в папку `ui`; CI проверяет SHA-256 изображений перед упаковкой.

Музыка переключается вместе с выбранным сервером: Наруто — Eastern Thought / Asian Drums; Solo Leveling — Darkling / Five Armies. Сохраняются громкость и выключение музыки; во время Minecraft музыка приостанавливается. Автор: Kevin MacLeod, CC BY 4.0, подробности в `ui/MUSIC_CREDITS.md` и настройках лаунчера. Это тематическая подборка. Для локальной сборки распакуйте `theme-music-v1.zip` из релиза `auth-bridge-current` в `ui`.
