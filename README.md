# SinsWorld Launcher 1.0.0

Обновлённый Python-лаунчер на основе присланного проекта. Minecraft 1.20.1, Forge 1.20.1-47.3.22 сохранены. Новый интерфейс — pywebview / Edge WebView2: тёмный минимализм, изумрудный акцент, новости, настройки и аккаунт.

## Что изменено

- Стартовое вертикальное окно без названия: плавное увеличение, бегущие Мелиодас и Хоук, простой зелёный прогресс-бар.
- Плашка плавно меняет текст по реальному состоянию: проверка / обновлений нет / обновление / установка.
- GitHub Releases вместо Яндекс Диска и Google Drive. Лаунчер и моды используют разные каналы и отдельные экраны прогресса.
- SHA-256, размер скачивания, staging модов, откат при ошибке замены. Неуправляемые пользовательские моды не удаляются.
- Windows-помощник замены EXE после закрытия процесса; сохранение предыдущего EXE.
- Формы аккаунта без почты; явное разделение локального ника и настоящей серверной авторизации.
- Подготовлен видеофон трейлера: приглушённый, без звука, с паузой и статичным запасным фоном. Сам трейлер не предоставлен.
- Приложены инструменты генерации манифестов, автоматические тесты и Windows GitHub Actions workflow.

## Запуск на Windows

Требуются Python 3.11, Microsoft Edge WebView2 Runtime и для игры Java 17.

1. Распакуйте архив в отдельную папку с правами записи.
2. Откройте `start_launcher.bat`. Он создаст новое окружение и установит зависимости.
3. При первом запуске откройте настройки. Заполните GitHub-репозиторий лаунчера и репозиторий модов в формате `owner/repository`. Можно указать один и тот же репозиторий.
4. Убедитесь, что опубликованы теги Release `launcher-current` и `mods-current` с правильными assets. Подробно: `docs/GITHUB_UPDATES.md`.
5. Укажите Java 17, если она не найдена автоматически, и адрес сервера при необходимости.

При незаданном GitHub отображается предложение настройки, а не фиктивная успешная проверка. В присланном архиве URL репозитория не было; он намеренно не выдуман.

## Сборка EXE

Запустите `build_windows.bat` на Windows. Результат — `dist/SinsWorldLauncher.exe` и `dist/launcher-manifest.json`. Альтернатива: загрузите содержимое проекта в корень GitHub-репозитория и вручную запустите приложенный Actions workflow.

В архиве нет старого EXE от предыдущей версии: он бы запускал прежний код. Исполняемый Windows-файл в Linux-среде этой работы не собирался и на Windows не запускался. Включены обновлённые исходники и воспроизводимая инструкция сборки.

## Аккаунты

Для регистрации и входа введите в настройках `auth_api_url` своего сервиса. Адаптер и контракт описаны в `docs/AUTH.md`. Готового сервера авторизации в исходном ZIP не было, поэтому автоматический вход в AuthMe не заявляется работающим без серверной интеграции. Временный локальный профиль ведёт себя как прежний ввод ника и явно подписан в интерфейсе.

Пароли не сохраняются. «Запомнить меня» использует системное защищённое хранилище для refresh token. Для собственной Yggdrasil-авторизации необходимы проверенный authlib-injector и серверная проверка сессий.

## Трейлер и демонстрация

`docs/UI_AND_TRAILER.md` описывает прямую HTTPS-ссылку на MP4/WebM. Страницу YouTube нельзя использовать вместо видеофайла. В `demo/Launcher_Updater_Demo.html` — независимый анимированный пример, который можно открыть в обычном браузере. Открытие `ui/index.html` в браузере показывает основной интерфейс, но реальные операции требуют запуска Python.

## Данные и обновления

Настройки и игра остаются в `%APPDATA%/SinsWorldLauncher/`. Старые параметры Яндекс Диска могут сохраняться в пользовательском config, но новый updater их не использует. Настройки из этой папки имеют приоритет над корневым config.

При миграции проверьте старую папку mods на дубликаты: новые обновления не удаляют чужие или изменённые пользователем JAR. Не запускайте два экземпляра лаунчера для одной папки игры.
