# Публикация автообновлений

Целевой аккаунт: Zairez1. Подготовленный репозиторий: Zairez1/SinsWorldLauncher (ещё не создан).

Windows workflow автоматически собирает и публикует новый лаунчер при изменении main. CI вшивает адрес текущего репозитория и версию 1.1.<номер запуска>.

После первой успешной Windows-сборки второй workflow импортирует существующий набор модов с публичной папки из исходного config и публикует его в Release mods-current. В дальнейшем моды можно публиковать ручным запуском Publish SinsWorld mods или push файлов в mods/. Игроки загружают обновления только из GitHub Releases.

Подготовка и локальные тесты выполнены. Репозиторий не создан, Actions не запускались, релизы пока не опубликованы. Для создания репозитория требуется браузер: подключённые инструменты GitHub не предоставляют соответствующей команды.
