# Автообновления SinsWorld

Репозиторий: https://github.com/Zairez1/SinsWorldLauncher

Windows workflow автоматически собирает и публикует лаунчер при изменении main. CI вшивает текущий адрес репозитория и версию 1.1.<номер запуска>. Клиенты проверяют канал launcher-current.

После первой успешной Windows-сборки второй workflow импортирует моды с прежней публичной папки Яндекс Диска и публикует их в mods-current. В дальнейшем моды можно обновлять кнопкой Run workflow у Publish SinsWorld mods или push файлов в mods/. Игроки скачивают обновления с GitHub Releases.

Первую успешную сборку и публикацию следует проверить в Actions и Releases. Пока опубликован исходный код, это само по себе не доказывает готовность EXE.
