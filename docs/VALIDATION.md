# Проверка сборки от 25.10.2026

## Выполнено

`python -m unittest discover -s tests -v`: **15 тестов пройдено**.

- Версии сравниваются численно; некорректные версии отклоняются.
- Проверены обход каталогов, Windows device names, симлинк за пределы игры, дубли имён без учёта регистра.
- Проверены установка и повторная синхронизация модов без повторной загрузки актуальных файлов.
- Проверено удаление всех JAR вне манифеста, включая локально изменённые и вложенные; настройки и сохранения остаются.
- Ошибка SHA-256 второго файла не изменяет старую рабочую сборку.
- Искусственная ошибка диска при замене второго файла вызывает откат первого и второго.
- Неверная версия Forge и отмена не приводят к установке модов.
- Asset из другого GitHub-репозитория отклоняется.
- Лаунчер определяет новую версию и проверяет размер/хеш EXE; неудачная загрузка не заменяет предыдущий файл.
- Настройки сохраняются. Регистрация при отсутствии API не имитируется; локальный профиль не помечается авторизованным.
- Проверен путь запуска уже установленного Minecraft, Java 17, память, fullscreen и Quick Play (запуск процесса замокан).
- Проверено, что стартовая проверка лаунчера не вызывает обновление модов.

Python-модули прошли `compileall`, JavaScript — синтаксическую проверку Node.

## Проверка интерфейса в Chromium

В Linux запущен Chromium 153 через Playwright, локальный HTTP-сервер и тестовый мост Python API. Фактическая отрисовка основного и стартового экрана просмотрена.

Проверены: завершение стартового экрана, навигация, сохранение настроек через мост, безопасный вывод HTML-подобного текста новостей, форма регистрации и показ кода восстановления, вызов запуска игры, смена статусов стартового окна и заполнение полосы на 62%. Ошибок JavaScript не зафиксировано.

Это проверка настоящего HTML/CSS и взаимодействия с **замоканными** ответами моста. Она не подтверждает работоспособность чужого сервера аккаунтов и не заменяет тест Windows WebView2.

## Не выполнялось

- Интерактивный запуск Windows EXE, Edge WebView2 и PowerShell-помощника на пользовательском Windows-компьютере. Сборка EXE на Windows runner уже выполнена успешно.
- Запуск полного Minecraft/Forge и подключение к игровому серверу.
- Полная установка всех модов на пользовательском ПК. Репозиторий уже настроен: Zairez1/SinsWorldLauncher; EXE и его SHA-256 скачаны и проверены.
- Запуск полного игрового клиента в CI. Репозиторий создан и launcher-current опубликован.
- Настоящая регистрация, восстановление аккаунта и вход на сервер без AuthMe: сервис и серверная интеграция не предоставлены.
- Просмотр трейлера: видеофайл/ссылка не предоставлены.

Перед раздачей игрокам выполните Windows-сборку и испытайте два релиза лаунчера и две версии набора модов на отдельной тестовой папке. Команды и структура релизов — в `GITHUB_UPDATES.md`.

## Актуальные референсы и исправление перезапуска

- 16 unit-тестов, включая сброс окружения при запуске helper.
- В Chromium проверены навигация, память, сохранение настроек, безопасный вывод новостей, регистрация, код восстановления и вызов запуска игры. API в этом тесте подменён; серверная авторизация не считается проверенной.
- В Windows CI tools/test_windows_restart.py собирает настоящий onefile EXE, выполняет замену через production apply_update.ps1, ждёт удаления старой временной папки и проверяет запуск нового процесса с отдельной распаковкой и рабочими импортами. Результат см. в соответствующем Actions run.
- Обновление после 1.1.3 использует PYINSTALLER_RESET_ENVIRONMENT=1 в Python и PowerShell и ждёт завершения Python-процесса и родительского onefile bootloader. Для перехода со старой версии после уже возникшего сбоя может потребоваться один ручной запуск нового EXE.
