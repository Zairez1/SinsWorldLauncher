# Опубликованный набор модов

Основа — 41 JAR из пользовательского mods(1).zip. Добавлены необходимые библиотеки: Player Animator 1.0.2-rc1+1.20 Forge с Modrinth автора и FTB Library Forge 2001.2.12 с CurseForge автора. FTB Library совпадает по SHA-256 с исходной сборкой пользователя. Встроенные Jar-in-Jar библиотеки MezzConfig, XaeroLib и Kotlin for Forge не дублируются отдельными JAR. Всего 43 файла.

Имена assets GitHub заменяют пробелы точками: Early Survival переименован в Early.Survival.-.Forge.-1.20.1-1.0.0.jar без изменения содержимого. Канонический список — modpack/mods-manifest.json; рабочий манифест прикрепляется к GitHub Release mods-current после всех JAR.

Java 17 загружается из runtime Mojang через minecraft-launcher-lib 7.1. Перед каждым запуском восстанавливаются файлы Minecraft и библиотеки Forge. Скачать сторонний произвольный мод из его метаданных клиент не пытается: зависимости включаются владельцем в проверенный список.

Полный графический запуск Minecraft и подключение к серверу не тестировались в Linux-среде разработки; наличие всех обязательных modId проверяется с учётом вложенных JAR.
