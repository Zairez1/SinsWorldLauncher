# Интерфейс SinsWorld

Приложение осталось Python-проектом; для анимации и видео интерфейс перенесён в pywebview / Microsoft Edge WebView2. Актуальные референсы — 01_launcher_home.png, 02_launcher_news.png, 03_launcher_settings.png, 04_launcher_register.png и 05_launcher_login.png, предоставленные пользователем после версии 1.1.3. Реальные HTML-элементы находятся поверх очищенных фоновых иллюстраций home-scene.png и inner-scene.png. Это заменяет оформление таверны из предыдущей версии. Масштабирование сохраняет пропорции 1672×941.

## Стартовое окно

Вертикальное окно без бренда, плавное увеличение из центра, зелёные бегущие силуэты Мелиодаса и Хоука, простой зелёный бар. Хоук использует очищенную альфа-маску. Смена текста — вертикальное появление/исчезновение примерно 280 мс. Системная настройка уменьшенного движения учитывается.

Здесь проверяется только EXE лаунчера. Настоящие события Python управляют состояниями и байтовым прогрессом; демонстрационные таймеры не запускают поддельное обновление.

- Проверка обновлений → обновлений нет → основной интерфейс.
- Проверка → обновление лаунчера → установка обновления → перезапуск.
- При недоступности GitHub или отсутствии настройки отображается причина, а не сообщение об успешной проверке.

## Основное окно

Название — SinsWorld. Тёмный изумрудный стиль, дракон слева, Мелиодас справа, навигация вверху: игра, новости, настройки; аккаунт справа. Настройки: игра (память, разрешение, полный экран, папка), Java и загрузки. Вход, регистрация и восстановление имеют работающие поля и кнопки. Новости показывают реальный news.json; демонстрационных событий в рабочем клиенте нет. Моды обязательно проверяются перед запуском игры. Стартовое окно проверяет только обновление EXE.

Новости читаются из необязательного asset `news.json` в релизе лаунчера:

```json
{"items": [{"title": "Обновление мира", "date": "2026-10-25", "body": "Текст новости"}]}
```

Содержимое отображается как текст, без исполнения HTML/JavaScript. При отсутствии новостей показано пустое состояние, при ошибке — повторная попытка.

## Видеофон

Трейлер не приложен, поэтому по умолчанию используется статичный арт мира. В настройке `trailer_url` предусмотрена прямая HTTPS-ссылка на MP4/WebM. Страница YouTube вместо видеофайла не подойдёт.

Трейлер воспроизводится без звука по кругу на фоне, плавно проявляется после загрузки и затемняется под интерфейсом. Есть пауза, при скрытии приложения видео приостанавливается. При ошибке остаётся статичный фон. При включённом уменьшении движения видео не запускается автоматически. Полностью бесшовная склейка зависит от исходного монтажа трейлера.

В `demo/Launcher_Updater_Demo.html` сохранён браузерный пример с ресурсами из ui/ стартового окна с кнопками проверки обоих сценариев. Он намеренно демонстрационный; рабочий экран находится в `ui/splash.html` и управляется Python.
